# 交接

**本页回答**：现在有什么活在路上、做到哪儿了、交给下一个会话要看什么。

这一区的规矩一句话：**有页 = 有活在路上，做完删**。一件活一页，页头是验收清单，正文是实施
方案；随做随提交，中途每次提交都是一份可交接的快照。做完把结论拆解归梁——设计进
[现状区](/docs)、决定落一张[轨迹卡](/trajectory)、没做的回[未来区](/future/roadmap)——
然后把那一页删掉。git 历史是它的档案。这一页本身是导读，不算活。

**此刻没有在途的活**——这一区只有这一页导读。侧栏上它旁边长出别的页，就是有活在路上。

## 什么样的活才升格成一页

**跨会话、跨模块、有未定选型**，三条占一条才写 spec；装得进一个会话的直接进模块页开工。
这个件目前所有的活都装得进一个会话——连「更名」那次也只是模块页加一张卡的事。
