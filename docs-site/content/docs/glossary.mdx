# 术语表

**本页回答**：文档里那个词到底指什么。收这个件自己造的、与通用词在这里有特定含义的词；
通用编程词不收。

## 这个件

| 词 | 是什么 |
| --- | --- |
| **作业机** | 这个件的形态：`submit` 秒回作业号、后台跑全链、终态事件。对应 `src/index.ts` 的服务，见[作业机](/docs/job-runner) |
| **作业** | 一次 PDF → markdown 转换的账（`Pdf2mdJob`）：输入、输出目录、状态、成败原因、产出三样。落盘就是它 |
| **状态机六态** | `queued → uploading → running → done \| failed \| interrupted`；后三个是终态，到任一不再自动变化——`failed` / `interrupted` 可经[续取](/docs/usage)手动翻回 `queued` |
| **串行 / 排队** | 作业一个接一个跑：前一个到终态才轮到下一个，没轮到的停在 `queued`。见[作业机](/docs/job-runner) |
| **作业账** | 作业记录的落盘副本，经 gwbData 存进文档 `jobs`。重启后靠它对账 |
| **进度**（`progress`） | 云端解析中报来的已解析页 / 总页，记在作业上；排队时没有，done 时补满。只记账，不推事件 |
| **停滞** | 云端在解析（running / converting）而状态与已解析页数一段时间都不动——作业按 failed 结算。排队不算停滞，只受总上限管。见[云端客户端](/docs/mineru-client) |
| **续取**（resume） | failed / interrupted 的作业凭账上 batchId 从云端轮询接着跑到终态——不重新申请位、不上传、**不重花解析额度**。云端结果留存有时限，过期只能重提。见[用法](/docs/usage) |
| **interrupted** | 宿主重启或件卸载打断的作业——账如实标注，不自动重跑；处置先续取（resume），续不了再重提。见[用法](/docs/usage)坑三条 |
| **零库概念** | 输入一个 PDF 绝对路径、一个输出目录，产出 markdown + images/。不知道 papers 存在，不做归档、不做成品命名 |
| **语言判定** | 正文 zh/en 的判定：CJK 字数 × 3 ≥ ASCII 字母数判 zh。老仓口径原样，见[解包与语言](/docs/extract) |
| **`job-settled`** | 作业到终态时经内核 emit 通道推的界面事件。给看着界面的人，不是给 agent 的回执 |
| **名不对应** | 件叫 `gwb-mineru`（说谁在干活：MinerU 引擎），服务与命令叫 `pdf2md.*`（说干什么：转换）。有意例外，见[那张卡](/trajectory/2026-09-08-engine-vs-function-naming) |

## gwb 线的词（在这里的含义）

| 词 | 是什么 |
| --- | --- |
| **件** | gwb 线的插件：一个 npm 包，装进 home、经 cordis 挂载，一仓一包一件。内核线的正本见 gwb-kernel 的文档站 |
| **home** | 件住的地方，一个普通的 npm 项目根；本件的凭据节 `mineru` 也住那边的 settings |
| **static inject** | cordis 的硬依赖声明：`static inject = ['gwbCommands', …]`——缺谁这个件不挂。本件对 settings / data / commands 用它 |
| **局部注入** | `ctx.inject(['gwbSkills'], …)` 那种可选依赖：没装 skills 件的 home 里作业机照常挂 |
| **gwbData** | gwb-data 件提供的小型落盘服务（`readDoc` / `writeDoc`）。作业账的存放处 |
| **设置节** | settings 里按件分的节。本件的节名 `mineru`（跟 cordis.yml 条目 id 走），键 `token`，类型 secret |
| **MinerU** | 云端 PDF 解析服务（mineru.net 精准解析 API v4），vlm 模型，公式表格都开，语言 ch（中英混合）。解析是分钟级的——作业形态的全部理由 |
| **`full.md`** | MinerU 结果 zip 里完整 markdown 的标准名。解包时优先认它，没有则要求 `.md` 唯一 |

## 文档与账本

| 词 | 是什么 |
| --- | --- |
| **docfirst** | 文档论断钉在真源码上的机制：引用记号 + git 记忆 + 账本。正本见 docfirst 站 |
| **钉码** | 页里指向某段代码的正式引用（`{/* ref … */}`）。代码一改就报黄，得人复核。只出现在现状区 |
| **六区** | docs / trajectory / spec / future / outputs / feedback——目录即状态，六种生命周期 |
| **轨迹卡** | `content/trajectory/` 一卡一文件，记方向了断，只增不改、不钉码 |
