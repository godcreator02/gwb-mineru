**gwb-mineru**：gwb 工作台的插件，把 PDF 交给 MinerU 云端转成 markdown。

给一个 PDF 绝对路径和一个输出目录，插件立即返回作业号，在后台完成申请上传位、上传、轮询、下载、解包，
把完整 markdown 与 `images/` 原样放进那个目录。别的插件 inject 服务 `gwbPdf2md`，agent 调命令 `pdf2md.submit`、
`pdf2md.status`、`pdf2md.jobs`、`pdf2md.recover`。插件叫 gwb-mineru、服务叫 pdf2md，名字不对应是有意的。

## 跑起来

```powershell
pnpm install
pnpm check          # 仓根：typecheck，再构建并跑单测（替身云端与现场生成的 zip，不联网、不花额度）
pnpm build          # 插件包在 plugins/mineru/，esbuild 输出 js 并把 adm-zip 打包进 dist/
```

装进 home：`plugin-manager.install {"pkg":"@godcreator/gwb-mineru"}`。用之前在设置节 `mineru` 里配 `token`（mineru.net 的 API 管理页创建）。
