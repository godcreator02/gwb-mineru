title: 跟进 gwb-settings 0.4.0 的凭据拆分
description: 来源：gwb-settings 凭据机制适配会话；破坏性版本发布前通知
---

上游计划发布 `@godcreator/gwb-settings@0.4.0`，这是命令语义与持久化格式的破坏性变更。本通知在发布前送达；采用时以源上已发布版本为准。

`settings.all` 只返回普通设置，`settings.get/set/delete` 不再处理 secret。凭据使用独立的 `credentials.*`：list/status/copy/import/generate/delete 不返回原文；set/reveal 仅允许 UI 与插件来源。内部 `ctx.gwbSettings.define/get/set/delete` 签名与字符串 secret 用法保持兼容。

每个 home 自己保存明文 `credentials.json`；`settings.json` 只保留普通值与元信息。升级迁移需保留已保存但当前没有插件定义的孤立凭据。跨 home 复制显式指定来源与目标，不隐式借用其他 home。

MinerU 内部 ctx.gwbSettings 读 token 可保留；缺失/过期错误与 pdf2md 说明书需移除 settings.set 的凭据配置指引。

适配后把 settings peer 跟到 `^0.4.0`，安装源上已发布版本并完成本仓 build/check 与文档检查。default 必须等整套下游适配完成后再切换；切换后核验 active 和 unmetPeers。实现结论写回现状文档后删除本通知。

依据：gwb-release 的破坏版下游通知要求；gwb-settings 的 credentials 命令与每 home 存储契约。
