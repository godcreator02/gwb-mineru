---
title: 迁移 kernel 0.8：浏览器模块通过代码登记，React 由 shell 提供
---

来源：gwb-kernel；日期：2026-09-27。目标版本 0.8.0，发布前通知。

本仓受影响的包：`@godcreator/gwb-mineru`。

kernel 将撤掉静态 React importmap 与 React 产物，改为 registerImports(mapping) 和 window.gwb.prepareImports(required?)。shell 配套提供 React 与纯 ./browser-imports 出口（browserImports()），React 保持 19.2.8。旧 shell 不能配新 kernel 单独启动。

需要做：

1. 在新内核隔离 home 验证，再将插件的内核 peer 范围改为 ^0.8.0；上游发布后才能写入正式依赖下限。
2. 带浏览器构建的包从 @godcreator/gwb-shell/browser-imports 导入 browserImports，以 Object.keys(browserImports()) 作为 external，停止读取 kernel 的 dist/index.html；shell peer 下限需包含代码出口。
3. 自己提供模块时导出纯 browserImports() 并在主进程用 ctx.effect 登记；使用其他提供方写明 peer，先保证其就绪。已注入地址改变后整页重载。
4. 适配通过后按 gwb-release 发补丁；default 必须等配套插件就绪再组合升级 kernel 与 shell，随后重启。

证据：D:/unitfolders/igldu-gwbkernel/gwb-kernel/docs-site/content/docs/seams/page-react.mdx；实验 probes/2609271940_preload-importmap；隔离 home browser-imports-2609271949。

本通知只说明迁移要求，不表示本仓已经适配或发版。处理完成后删除本条。
