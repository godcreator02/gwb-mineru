---
title: 跟进 gwb-kernel 0.10：gwb.log 改成一行一个 JSON
---

来源：gwb-kernel。用户于 2026-09-27 定下日志改为「内核写结构化文件、插件只读」，并选择直接升内核 0.10.0（日志行格式在内核的契约清单里，改它就升 x）。

内核包的接口类型、IPC 通道、`gwbKernel` 的成员都没变。变的只有 `<home>/gwb.log`：一行一个 JSON `{ ts, level, source, name, msg }`（键与顺序固定），不再是「时间 级别 名字 正文」的文本；另外内核按条目写 `loader` 的挂载日志（挂上、挂载失败、卸载、退回等待，条目树安定后一行汇总）。

本仓涉及：plugins/mineru/package.json。

要做的：在 0.10 内核的隔离 home 里验过之后，把 peer 里内核包的范围改成 `^0.10.0` 并发补丁版。代码里若按文本格式读 `gwb.log`，改成按行 `JSON.parse`；插件自己的 logger 名不要用 `kernel`、`loader`、`include`、`renderer`（这几个名字的日志算内核或页面的）。

证据：内核仓 `docs-site/content/docs/seams/log.mdx`（文件格式与约定）、`docs-site/content/future/spec/log-kernel-writes-plugins-read.mdx`（跨仓清单与 `logger.query` 的形状）、提交 `7ea49c1`。
