`@godcreator/docfirst-workflow` 0.3.0 是破坏性版本。本站 `docs-site/package.json` 里钉的是旧版精确号，不跟就不受影响；
跟的时候照下面做一遍。设计与理由见 god-live-doc 站的轨迹卡 `2026-09-25-records-live-in-markers`、
`2026-09-25-drift-handled-in-same-commit`、`2026-09-25-zones-by-convention`、`2026-09-25-outputs-render-from-source-text`，
god-live-doc 自己的迁移提交是 `e3a0b36` 到 `b32ff74`，可以照着看。

## 变了什么

- **没有记录簿了**：确认时的记录（段哈希、blob 名）写在记号自己的属性上，`.ledger.json` 删掉。记号长这样：
  `{/* ref file="../src/a.ts" lines="10-23" hash="3fa9c2e1b07d" blob="2689fa073ac6" */}`
- **确认不要求先提交**；`confirm` 只做机械写回（草稿换正式记号、挪了位置的写回行号、重新生成生成正本），
  黄灯要复核后 `docfirst confirm <页…> --accept` 点名签
- **`check` 把本仓未提交改动引起的黄灯算红**：改了被钉的代码，要在同一个提交里复核并 `--accept`
- **分区按约定**：`content/` 下只有 `trajectory/`、`future/` 两个固定名字，其余目录都是现状区、都进 `check`。
  在途方案放 `future/spec/`，别的仓投来的反馈放 `future/inbox/`（一条一个文件），hatch 不再有
- **配置只认 `formats` / `content` / `components` / `outputs` 四个键**，写了别的键直接报错并说明怎么改
- **生成正本按原文渲染**：记号换成代码块，其余文字一个字节不动（行内代码的反引号不再被转成 `&#x60;`）。
  正本里不能用 JSX 组件或别的 mdx 表达式；`render` 只处理挂了 `outputs` 映射的页，不再有 `out/`

## 怎么迁（在站目录 `docs-site/` 里）

1. `package.json` 里 `@godcreator/docfirst-workflow` 改成 `0.3.0`，`pnpm install`
2. `pnpm docfirst migrate-ledger`：把 `.ledger.json` 的记录写进各记号并删掉它，最后打印配置里要删的键
3. 改 `docfirst.config.mjs`：删掉 `docs`、`trajectory`、`comparator`、`ledger`、`fumadocs`、`out`；内容根不叫 `content` 才写 `content`
4. 挪区：
   - `content/outputs/` 下的正本挪进现状区（比如 `content/docs/outputs/`），`outputs` 映射左边的路径跟着改
   - `content/spec/` 下的页挪进 `content/future/spec/`
   - `content/feedback/inbox.mdx`（有的站叫 `inbound.mdx`）每一条拆成 `content/future/inbox/<日期>-<来源>-<英文短标题>.mdx`，
     已处理的删掉；`hatch.mdx` 里还有用的条目改写进路线图或轨迹卡，然后删掉
   - `source.config.ts` 删掉 spec、outputs、feedback 三个集合；`src/lib/source.ts`、侧栏、`src/app` 下对应的三条路由一起删
   - 站内指向 `/spec`、`/outputs`、`/feedback` 的链接改掉
5. `pnpm docfirst render`：生成正本里有组件的会报出来，改成纯 markdown
6. `pnpm docfirst check`：迁移后记录跟原来一致，一般是绿的；`pnpm docfirst confirm` 做一次机械写回
7. 站的测试里用了 `collectionOf`、`listing.orphans` 的删掉（这两样没了）；`pnpm build`
8. AGENTS / CLAUDE 正本里写着「先 commit 再 confirm」「六区」的改掉；docfirst 的规矩以插件随带的说明书 `docfirst-docs` 为准

装配插件 `@godcreator/gwb-docfirst-workflow` 0.7.8 起按这个结构铺新站。
